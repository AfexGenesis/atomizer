# Atomizer
Molecular Visualisation 

Starts from the Terminal:
`atomizer input <filename.cif>`

## Installation for Fedora

1. Clone the DirectXMath repository from Microsoft
2. Enable Copr in Fedora for @robotics-sig/directx-shader-compiler
3. Install Vulkan SDK and run the setup-env.sh and source the .bashrc
4. Update the .bashrc if the DXC defaults to Vulkan's DXC
5. Copy DirectXMath/Inc/* and Paste it at /usr/local/include/ use sudo
6. Clone the corert repository from dotnet Archived version
7. Copy corert/src/Native/inc/unix/sal.h and Paste it at /usr/local/include/
8. Custom install a newer CMake version if needed update the .bashrc

`Final software does support Windows` & `Main support linux distribution is Fedora`
